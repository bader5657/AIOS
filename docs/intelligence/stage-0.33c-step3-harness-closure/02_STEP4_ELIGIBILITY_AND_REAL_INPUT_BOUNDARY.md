A future separately bounded Step 4 governance package must select and approve
real retained evidence and trusted business facts. It must bind those values to
the merged repository commit, harness SHA-256, governed interpreter and callable,
canonical input algorithm, and later evidence requirements. This package makes

one bounded production write remains Step 7. The harness's availability does
not collapse or bypass those gates.
