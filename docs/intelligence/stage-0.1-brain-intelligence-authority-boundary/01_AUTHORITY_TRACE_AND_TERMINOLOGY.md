## Authoritative mapping

`Intelligence = implementation/governance phase for realizing intelligence/inference capability within the existing Blueprint Brain architecture.`

It is not `AIOS Core → Intelligence Layer → AIOS Brain`. The Blueprint remains
the architectural Source of Truth.
