# Prohibited Scope

This package authorizes no:

- SQL or migration file;
- database, schema, table, column, constraint, or index creation;
- PostgreSQL connection, credential, query, transaction execution, or data;
- ORM/driver selection or dependency installation;
- Registry Python/runtime code, API, model, or Registry Entry;
- runtime/configuration/test/schema/Docker/deployment/service change;
- production connection or rollback;
- historical Registry restoration or cherry-pick;
- Request Context wholesale persistence;
- new metadata, relationship, status, duplicate, or business semantics;
- Stage 5.2.2, 5.3, or 5.4 work; or
- Blueprint, Frozen Roadmap, architecture, Stage 3, Stage 4, or Stage 5.1.x
  modification.

The authorized repository change is closed to this governance directory.
