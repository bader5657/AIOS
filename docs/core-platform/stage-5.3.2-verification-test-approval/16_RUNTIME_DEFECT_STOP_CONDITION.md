# Runtime Defect Stop Condition

Runtime files are not authorized.

If an approved test exposes a genuine Registry runtime defect, Stage 5.3.2
implementation stops and reports exactly:

`STAGE 5.3.2 RUNTIME CORRECTION APPROVAL REQUIRED`

The report must identify the failing scenario, exact defect, evidence, and
smallest proposed runtime path scope. No fix, workaround, weakened assertion,
schema change, or expanded test framework may be made under this package.
