- the approval is **PUBLISHED**;
- the exact Stage 8.1.4 implementation authority is **ACTIVE**; and
- Stage 8.1.4 becomes `INTEGRATION APPROVED — READY TO BUILD`.

branch, modify only authorized paths, pass all gates, receive review, and use a
separate verification/closure lifecycle.
