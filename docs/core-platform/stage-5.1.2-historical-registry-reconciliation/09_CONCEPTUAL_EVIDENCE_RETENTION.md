# Conceptual Evidence Retention

The following historical concepts may remain non-authoritative evidence:

- an identity concept;
- a represented media/input identity concept;
- a storage/file-location concept;
- a Document Manifest reference concept; and
- absence of original binary content from the historical record.

They demonstrate only that similar concerns appeared historically. They do
not approve `id`, `media_type`, `storage_path`, `manifest_path`, their values,
types, requiredness, serialization, object ownership, API placement, or
database representation.

**Evidence reuse != implementation reuse.**

Later authority may accept, rename, reshape, or reject every historical name.
This record creates no preference beyond the five Active responsibility
categories.
