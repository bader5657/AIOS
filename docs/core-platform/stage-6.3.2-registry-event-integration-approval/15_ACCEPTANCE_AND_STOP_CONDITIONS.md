# Acceptance and Stop Conditions

Acceptance requires exact conformance to this one-event, gate-only integration
and exactly four authorized implementation/test paths.

Implementation must stop if Domain Foundation, Event Engine runtime, Registry,
Asset Pipeline, Document Manifest, adapter, migration, config, dependency, or a
fifth path appears necessary; if a concrete event must be invented; if schema
version is guessed; if multiple-event semantics emerge; or if mandatory tests
fail. Scope correction requires separate Project Owner approval.
