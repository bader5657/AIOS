# Brain, Specialist, and Memory Separation

AIOS Core is not Brain. Stage 7 names only `AIOS_BRAIN_BOUNDARY`; it authorizes
no Brain API, invocation, LLM, model selection, prompt, or reasoning.

AIOS Core Route is not Specialist Router. It cannot choose/register/call
Specialists or inspect specialist capabilities. It cannot read, write, select,
or maintain Memory or conversation/session memory. These remain later-stage.
