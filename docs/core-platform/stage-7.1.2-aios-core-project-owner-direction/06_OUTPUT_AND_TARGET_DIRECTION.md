# Output and Target Direction

Stage 7.2.1 must define a minimal runtime-neutral bounded routing disposition
covering success/allowance, target, and bounded non-success information.

The only permitted positive Stage 7 target is `AIOS_BRAIN_BOUNDARY`, meaning
eligible for a future handoff. It is not a Brain instance, call, API, model,
provider, Specialist, Memory, business-domain, or tool target. Exact DTO,
fields, code values, and target representation remain deferred.
