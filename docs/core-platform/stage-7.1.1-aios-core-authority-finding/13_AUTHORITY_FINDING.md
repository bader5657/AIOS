# Authority Finding

`AIOS CORE BEHAVIOR UNDEFINED`

Active authority defines AIOS Core's pipeline position, Route ownership, and a
bounded handoff direction. It does not define enough executable semantics to
write a contract without invention: concrete input/output, Route decision,
validation, result and failure model, API, sync/async model, state,
determinism, orchestration, payload inspection, Brain invocation, or permitted
dependencies remain unresolved.

Under the strict authority test, position plus ownership is insufficient.
Historical implementation cannot fill the gap.
