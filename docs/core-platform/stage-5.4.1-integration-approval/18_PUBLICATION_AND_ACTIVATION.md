# Publication and Activation

Publication requires a normal PR merge containing only this governance
directory, preserving the exact baseline and Project Owner decisions, with no
runtime, test, dependency, schema, migration, database, deployment, or earlier
authority change.

Upon accepted merge to `main`, this package is Published as the official Stage
5.4.1 pre-implementation approval record. The Project Owner instruction
explicitly authorizes activation after publication and a passing post-merge
audit.

When Active, Stage 5.4.1 is **READY TO BUILD** only within the four exact paths
and contracts recorded here. Activation does not implement, test, connect,
migrate, deploy, verify, or close Stage 5.4.1.
