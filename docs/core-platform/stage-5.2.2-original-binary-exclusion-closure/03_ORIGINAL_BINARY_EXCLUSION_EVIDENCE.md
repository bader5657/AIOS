# Original-Binary Exclusion Evidence

`ORIGINAL BINARY IN POSTGRESQL REGISTRY = PROHIBITED`

The prohibition covers every representation of original business-file
content, including:

- PostgreSQL `BYTEA`;
- a BLOB-equivalent value;
- base64-encoded original content in text or JSONB;
- embedded original file/document bodies;
- binary content hidden inside metadata or relationship JSONB;
- complete Document Manifest embedding that duplicates original content; and
- any representation that transfers original-file ownership to Registry.

The approved Stage 5.2.1 table contains no binary column or file-body concept.
References and structured metadata do not authorize original content by
implication.
